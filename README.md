# 生活垃圾焚烧发电厂运行管理平台

面向垃圾进厂计量、垃圾池管理、焚烧炉与余热锅炉运行、汽轮发电机组、烟气净化与在线排放监测、飞灰固化与炉渣处理、渗滤液处理、设备点检检修与值班交接的一体化生活垃圾焚烧发电厂运行管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `waste-to-energy-plant:entries` 这一项，或调用 `resetModule(模块)`。

### 收运车辆与承运单位准入台账（`access`）

承运单位换得勤，进厂时要能立刻说清这家单位、这台车还能不能拉。判定口径全平台只有一份，
集中在 `frontend/src/data/access-core.ts` 的 `judgeAccess`：登记、补录、历史导入、待核清单
全部调它，页面上没有任何人工勾选项。

- **逐台登记**：一个承运单位下面按收运车辆逐台登记，每台车挂准运证编号、发证机关与到期日。
- **准入结论自动算**：距到期不足十五天（剩余 0~14 天）标「临期」；到期日已过的记录**不允许保存**
  （表单、补录同一闸口）；已在账的记录随基准日推移由 `reconcile` 自动翻成「已过期」。
- **唯一性口径**：
  - 同一台收运车辆在同一家承运单位下不能重复登记（判定键 = 承运单位 + 归一化车牌）；换单位
    必须按新单位重新登记一版；
  - 准运证编号在同一个发证机关下不能重号（判定键 = 发证机关 + 准运证编号），后提交的会被拒收
    并提示该证已被哪一家单位的哪台车占用；不同发证机关的同编号允许并存。
- **准运证补录**：同一张证重复递送只保留一条、以最后一版为准（版本号递增）；补录换成新证后
  版本重新计为 1；两台车同时补录同一张证，只保留先提交的那一台。
- **历史台账导入**：支持按「承运单位,车牌,准运证编号,发证机关,到期日,登记日期,备注」粘贴导入，
  按当时登记的到期日对齐，重复导入不会多出一份（已在账的同一台车跳过且不覆盖到期日）；
  同一份文件内同号证冲突只保留先出现的行；历史过期证照单导入并自动标「已过期」（历史数据不走
  人工登记的过期禁存闸口）。
- **进厂待核清单**：`垃圾进厂计量` 页底部按未复核计量单生成待核清单，以「承运单位 + 车牌」
  实时对齐台账并同步准入结论与门岗处置（放行 / 临期限期 / 禁止入厂 / 查无准入禁止入厂），
  门岗登记到车不填结论；同车牌挂多家单位且未报承运单位时提示人工核对。

判定与冲突规则有一份不依赖浏览器的自测：

```bash
cd frontend
npm run test:access   # 24 条用例：到期边界、唯一键、补录版本、导入幂等、待核同步
```
